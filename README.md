# 📝 NoteSpace – Offline Notes Application

NoteSpace is a modern, responsive offline notes application designed to help users capture, organize and manage their notes efficiently. It provides a clean interface with category-based organization and local device storage, allowing users to access their notes without an internet connection.

## ✨ Features

- **Create Notes:** Quickly create and save notes.
- **Search Notes:** Find notes by title or content.
- **Pinned Notes:** Keep important notes easily accessible.
- **Recently Edited:** Access recently modified notes.
- **Categories:** Organize notes into General, Work, Personal, Study and Ideas.
- **Offline Support:** Access the application without an internet connection.
- **Responsive UI:** Clean and user-friendly interface.
- **Local Storage:** Store notes on the user's device.

## 🛠️ Technologies Used

- C#
- ASP.NET Core
- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Service Workers
- Web App Manifest

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/sonalisethi2404-a11y/Offline-Notes-Application.git
   ```

2. Open the project folder in Visual Studio 2022.

3. Open `MyOfflinePWA.csproj`.

4. Restore the required NuGet packages.

5. Run the application using Visual Studio or:

   ```bash
   dotnet run
   ```

6. Open the local URL displayed in the terminal.
